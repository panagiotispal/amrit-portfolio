# Amrit Pal — Junior Frontend Developer Portfolio

Personal developer portfolio showcasing my frontend engineering projects, full-stack web applications, and software architecture background. Built from scratch with semantic HTML5, modern CSS3, and vanilla JavaScript without external UI frameworks.

**Live Demo:** [View Portfolio](https://panagiotispal.github.io/amrit-portfolio/)

---

## Key Features & Architecture

* **Interactive 3D Hero Portrait:** Custom mouse-tracking perspective tilt built with vanilla JavaScript and CSS 3D transforms.
* **Bento Grid & Cursor Spotlight:** Responsive project cards featuring dynamic radial gradient lighting that follows cursor coordinates.
* **Live Category Filtering:** Instant client-side filtering across Web/Frontend, Full-Stack, and Desktop/3D implementations.
* **Architecture Inspector Modal:** Accessible popup modal displaying detailed technical highlights for each project without page reloads.
* **Interactive Tech Stack Explorer:** Dynamic skill selector demonstrating real-world application of each technology across my projects.
* **Zero Dependencies:** Pure HTML5, CSS3, and ES6+ JavaScript ensuring maximum performance and fast load times.
